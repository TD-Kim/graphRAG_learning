실행: `streamlit run 01_basics.py` / `streamlit run 02_chatbot_ui.py`

## 가장 먼저 알아야 할 것: Streamlit 은 매번 위에서부터 다시 실행된다

버튼을 누르거나 입력할 때마다 **파일 전체가 처음부터 다시 실행**된다.
그래서 일반 변수는 매번 초기화되고, 남겨야 하는 값은 `st.session_state` 에 넣어야 한다.

```
사용자가 입력 ─▶ 파일 전체 재실행 ─▶ session_state.messages 로 이전 대화를 다시 그림 ─▶ 새 입력 처리 ─▶ messages 에 추가
```

이 한 가지를 이해하면 챗봇 코드의 구조가 전부 설명된다.

## "왜"

- **메시지에 `tool_calls` 를 같이 저장 (84, 96, 115줄)**: 재실행 후에도 도구 호출 Expander 를 다시 그리려면 그 정보가 기록에 있어야 한다.
- **`:=` (월러스 연산자) (76줄)**: 입력이 있을 때만 블록을 실행하면서 값을 변수에 받는다.
- **`st.rerun()`**: 상태를 바꾼 뒤 즉시 화면을 새 상태로 다시 그린다(삭제 버튼 등).
- **위젯 `key`**: `key="user_input"` 을 주면 값이 자동으로 `st.session_state.user_input` 에 들어간다.
- **스트리밍 효과는 가짜**: 여기서는 완성된 문자열을 한 글자씩 보여 줄 뿐이다. 진짜 스트리밍은 LLM 이 토큰을 내보내는 대로 그리는 것(final_chatbot 에서).
