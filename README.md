# 프로젝트 명  graphRAG_learning

## 소개
이 프로젝트는 graphRAG 를 구축하는 학습용 프로젝트 입니다.

## 주요 기능
1. NEO4j DB 연결
2. txt, csv, pdf to kg
3. automation tools 사용방법
4. streamlit 활용 챗봇 구현

## 사용 방법
0. 소스 다운로드 후 로컬 구동
1. 각 실습 패키지별 README.md 참조

## AI Engineering Learning Lab (확장 트랙)

기존 강의 실습(`part1`~`part4`)은 그대로 두고, AI 엔지니어링 전반(딥러닝 원리 → LLM 학습 → RAG → GraphRAG → Fine-tuning → AI 서비스)을 **직접 구현 + 라이브러리 비교** 방식으로 학습하는 트랙을 추가합니다. 새 실습은 `part1_ai_fundamentals/` ~ `part6_ai_service/` 폴더에 순서대로 만들어집니다.
