# experiments/ — 실험 기록 (포트폴리오)

학습·벤치마크·파인튜닝을 실행할 때마다 기록을 남긴다. 결과가 기대보다 나빠도 그대로 기록한다.

## 폴더 규칙

```
experiments/
├── README.md                          # 이 파일 (템플릿 포함)
├── INDEX.md                           # (첫 실험 때 생성) 실험 목록 표
└── 2026-11-16_P0-02_gpu-check/        # <날짜>_<실습ID>_<요약>
    ├── RECORD.md                      # 아래 템플릿
    ├── results.csv                    # 수치 결과
    ├── freeze.txt                     # uv pip freeze
    └── *.png                          # 그래프
```

- 모델 체크포인트, 대용량 인덱스, 원본 데이터는 커밋하지 않는다.
- 같은 실험을 설정만 바꿔 반복하면 같은 폴더의 `results.csv` 에 행을 추가한다.

## RECORD.md 템플릿

```markdown
# <실습ID> <실험 제목>

- 날짜:
- 관련 실습: (예: P3-12) / 코드 경로:

## 1. 목적
무엇을 확인하려는가? 가설은? (개선을 가정하지 말고 "확인할 질문"으로 쓴다)

## 2. 데이터셋
이름 / 출처 / 라이선스 / 크기(문서·질문 수) / train·test 분리 방법

## 3. 모델
이름 / 크기 / 라이선스 / 양자화 여부

## 4. 하이퍼파라미터
| 항목 | 값 |
|---|---|
| seed | |
| batch size | |
| learning rate | |
| epochs / steps | |
| max seq length | |
| (검색) top_k, k1, b, RRF k, α | |

## 5. 실행 환경
GPU / 드라이버 / torch·CUDA 버전 / 주요 라이브러리 버전 (`freeze.txt`)

## 6. 자원 사용량
| 항목 | 값 |
|---|---|
| GPU 최대 메모리 (`torch.cuda.max_memory_allocated`) | |
| 학습 시간 / 질의당 지연(p50·p95) | |

## 7. 결과
표 / 그래프 (results.csv 요약)

## 8. 비교
baseline 또는 비교군(라이브러리 구현, 이전 실험) 대비 차이. 차이가 통계적으로 의미 있는가? (반복 횟수·편차)

## 9. 해석과 개선점
왜 이런 결과가 나왔는가? 다음에 바꿔 볼 것은?
```
